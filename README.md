# 简账 (JianZhang) — Android 版

极简 · 本地 · 私密 的个人记账应用，由桌面版（Tauri 2 + Vue 3）移植而来。

## 特性
- 记账：收入/支出、金额、分类（内置 + 自定义）、账户、标签、日期、备注（≤40 字）
- 多账户：现金、银行卡、微信、支付宝、信用卡、投资等；净资产、资产与负债实时结算
- 账户间转账：转出/转入、手续费、备注与日期，余额计算与桌面版一致
- 流水：按月分组、全部/支出/收入/转账筛选、全文搜索、账户与标签筛选、多选批量分类/改账户/加标签/删除
- 概览：净资产、月度收支、环比/同比、近 6 个月趋势、每日支出、分类图表
- 统计：本月/近 3 月/近 12 月/本年/自定义区间、标签过滤、同比/环比、年度 12 月视图、分类排行
- 周期记账：每天/周/月/年、任意间隔、结束日期、自动入账或提醒后确认；已结束规则自动停用
- 标签：新增、编辑、删除、账目多标签与区间标签统计
- 提醒：预算接近上限/超支、账单到期、每日/每周记账提醒；支持应用内提醒中心和 WorkManager 系统通知
- 预算：设置每月总预算与分类预算，实时进度、结余 / 超支、剩余日均可用额度
- 数据管理：导出/导入 v2 完整备份（分类、账目、预算、账户、转账、标签、周期规则），兼容桌面版和旧 v1 备份；导出 CSV 流水
- 安全：启动密码锁屏、修改密码、立即锁定；密码加盐哈希存储
- 设置：字体、外观、默认账户、记账偏好、提醒开关与时间、分类管理
- AI 分析：配置 DeepSeek 或其他 OpenAI 兼容接口，用本机账本数据生成财务健康、消费结构、预算风险或自定义分析；API Key 仅存本机
- UI：底部导航收敛为概览/流水/账户/统计/更多；减少嵌套卡片与阴影，保留克制的动态 HUD 语言，图表支持点按查看数据

## 隐私保证
- 应用源码仅声明 `INTERNET` 与 `POST_NOTIFICATIONS`：前者只在用户主动点击 AI 分析时使用，后者只在用户开启系统提醒后使用
- WorkManager 合并清单会加入 `WAKE_LOCK`、`ACCESS_NETWORK_STATE`、`RECEIVE_BOOT_COMPLETED`、`FOREGROUND_SERVICE` 等系统调度权限，用于周期记账与提醒的可靠执行；简账自身不会在这些后台任务中上传账本数据
- 允许用户填写的本地 HTTP 模型端点（例如 Ollama / LM Studio）；默认和推荐使用 HTTPS
- 账本数据不会自动上传；AI 请求仅发送由当前账本聚合生成的分析上下文和用户补充问题
- 数据仅存于应用私有目录 SQLite（`jianzhang.db`），不申请存储权限
- 关闭 Android 系统备份（`allowBackup=false`），数据不会进入云端备份
- 备份文件格式与桌面版互通（`jianzhang-backup`），可在手机与电脑之间互相迁移

## 技术栈
- Kotlin 2.1.20 + Jetpack Compose（BOM 2025.05.01）+ Material 3
- Room 2.7.1（SQLite，数据模型与桌面版一致：金额以"分"存储）
- 图表全部使用 Compose Canvas 自绘（无第三方图表库，包体更小、动效可控）
- minSdk 26（Android 8.0），targetSdk 35

## 构建
### 方式一：Android Studio
1. 用 Android Studio（自带 JDK）打开本目录
2. 设置 SDK：`local.properties` 中 `sdk.dir` 指向 Android SDK 路径
3. 同步后运行 `assembleRelease` / `assembleDebug`

### 方式二：命令行（本项目开发机）
需要 JDK 17+ 和 Android SDK 35。项目使用 Gradle Wrapper：
```powershell
cd JianZhang-Android
.\build.ps1 assembleRelease
```
产物：`app\build\outputs\apk\release\app-release.apk`。若未配置 `keystore.properties`，release 会回退为 debug 签名。

> 依赖仓库已配置阿里云镜像（见 `settings.gradle.kts`），国内网络可直接下载。
> 发布版 APK 约 1.9 MB（R8 压缩后），远低于 30 MB 目标。
